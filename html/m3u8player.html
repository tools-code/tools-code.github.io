M3U8 Player FAQ

Q What is an M3U8 player?
An M3U8 player (also called an HLS player) parses an .m3u8 playlist and plays the underlying TS or fMP4 video segments in your browser. It is the standard way to preview live streams or test HLS sources.
Q How do I play M3U8 in Chrome?
Chrome cannot play M3U8 natively. This page uses hls.js to parse the playlist and feed the segments into Media Source Extensions, so playback works the same way as in Safari – just paste your URL and click Play.
Q Why will my M3U8 URL not play?
The three most common reasons are: CORS (the server must return the right Access-Control-Allow-Origin header), mixed content (an http:// URL will be blocked on an https:// page), and expired tokens in the playlist URL. Click Try Example first – if the sample plays but yours does not, the issue is with your URL.
Q GitHub M3U8 player project vs this online tool?
GitHub projects usually require cloning, installing dependencies, and running a build before you can test a stream. This online tool has zero setup – paste a URL and you are playing in under five seconds. Use GitHub projects when you need to embed a player in your own app; use this page for quick one-off tests.

M3U8 Player Source Code (HTML + JS)

The full source of the player on this page, in a single HTML snippet:

<video id="v" controls></video>
<script src="https://cdn.jsdelivr.net/npm/hls.js@1.5.13/dist/hls.min.js"></script>
<script>
if (Hls.isSupported()) {
  const hls = new Hls(); hls.loadSource(url); hls.attachMedia(v);
} else if (v.canPlayType('application/vnd.apple.mpegurl')) { v.src = url; }
</script>
